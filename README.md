## 중력 이상 현상

### 측면 중력

중력이 옆 방향으로 전환되어 벽면이 새로운 지면이 됩니다. 벽면을 기어다니는 거미형 개체를 상대하며 변화한 지형에 적응해야 합니다.

### 주기적 중력 변동

일정 주기마다 중력 방향이 바뀝니다. 바위벌레는 플레이어 아래쪽을 공격하므로, 그래플링 훅을 이용해 공중 위치를 적극적으로 확보해야 합니다.

### 무중력

중력이 사라진 구역입니다. 일반 이동이 제한되며, 그래플링 훅을 사용해 지형지물 사이를 이동해야 합니다.

## 기술 구조

* **Rigidbody 기반 Player Controller**
  이동, 점프, 달리기, 웅크리기와 사격 반작용을 Rigidbody 물리 기반으로 구현했습니다.

* **Zone 기반 중력 Preset**
  고정 방향 중력, 주기적 중력 전환, 무중력 상태를 구역별 Preset으로 구성했습니다.

* **Player·Camera 중력 동기화**
  중력 변경 시 공통 기준 방향을 바탕으로 플레이어와 카메라의 회전을 함께 보정했습니다.

* **그래플링 이동 연동**
  그래플링으로 전달되는 외부 힘이 플레이어의 속도 처리 과정에서 사라지지 않도록 이동 로직과 연동했습니다.

* **구역 기반 게임 진행**
  각 존의 몬스터 처치 상태에 따라 다음 구역을 차단하거나 개방하는 게임 진행 구조를 구현했습니다.
