# SinkPoint MVP 게임 기획서

## 1. 프로젝트 요약

**가제:** SinkPoint  
**장르:** 3D 액션 + 탐사 + 중력 변칙  
**목표 플레이타임:** 5-15분  
**개발 목표:** 4일 안에 처음부터 엔딩까지 플레이 가능한 MVP 완성

플레이어는 정체불명의 대형 싱크홀 내부를 조사하기 위해 투입된 전투요원입니다. 싱크홀 내부에서는 깊이 내려갈수록 물리 법칙이 무너지고, 중력 방향이 바뀌거나 중력이 사라지는 이상 현상이 발생합니다.

최종 목표는 싱크홀 최하부까지 내려가 이상 현상의 근원을 스캔하고 게임을 종료하는 것입니다.

## 2. MVP 목표

이번 MVP는 아래 플레이 루프 하나를 완성하는 것이 목표입니다.

```text
이동 -> 사격 -> 적 처치 -> 중력 변화 -> 무중력 -> 그래플 이동 -> 최하부 도달 -> 스캔 -> 엔딩
```

완성형 게임을 만드는 것이 아니라, **중력이 변하는 공간에서 실제로 이동하고 전투하고 끝까지 진행할 수 있다**는 것을 증명하는 프로토타입을 만듭니다.

## 3. 핵심 방향

### 중력이 메인 시스템

전투는 메인 시스템이 아니라 중력 변화를 보여주기 위한 보조 요소입니다. 플레이어가 기억해야 하는 장면은 방의 중력이 바뀌고, 플레이어와 적, 잔해가 함께 새로운 방향으로 떨어지는 순간입니다.

### 스코프는 작게 유지

4일 안에 끝내야 하므로 핵심 루프와 직접 관련 없는 기능은 과감히 제외합니다. 복잡한 AI, 무기 다양화, 인벤토리, 컷신, 보스전은 MVP 범위가 아닙니다.

### 플레이 가능 상태가 먼저

초기 구현에서는 Capsule, Cube, 임시 UI, 단순 콜라이더를 사용해도 됩니다. 아트 완성도보다 처음부터 엔딩까지 막히지 않고 플레이되는 것이 우선입니다.

## 4. 스테이지 구조

맵은 거대한 오픈월드가 아니라 하나의 수직형 스테이지입니다. 짧은 구간을 순서대로 통과하는 구조입니다.

```text
Entry
  ↓
Zone 01 - Entry
  ↓
Zone 02 - Normal Gravity
  ↓
Zone 03 - Gravity Shift
  ↓
Zone 04 - Reverse Gravity
  ↓
Zone 05 - Zero Gravity
  ↓
Zone 06 - Source
```

각 구간은 짧고 명확해야 합니다. 플레이어가 다음에 어디로 가야 하는지 헷갈리지 않는 것이 중요합니다.

## 5. 구역별 기획

### Entry

목적:
- 플레이어 시작 지점
- 싱크홀 조사 분위기 전달
- 안전하게 첫 이동을 시작하는 공간

필수:
- 플레이어 스폰 위치
- Normal Gravity 구역으로 이어지는 경로

### Normal Gravity

목적:
- 기본 조작 학습
- 이동, 카메라, 점프, 사격 확인

필수:
- WASD 이동
- 마우스 카메라 회전
- Space 점프
- 좌클릭 사격
- 적 1마리 이상 배치

제외:
- 복잡한 엄폐 전투
- 무기 교체
- 고급 적 AI

### Gravity Shift

목적:
- 중력이 아래가 아닌 다른 방향으로 바뀌는 경험 제공
- 벽이 바닥처럼 느껴지는 구간

필수:
- 구역 진입 트리거
- 중력 방향 변경
- 플레이어가 새 중력 방향에 맞게 이동
- Rigidbody 오브젝트가 새 중력 방향으로 떨어짐

제외:
- 자연스러운 시네마틱 연출
- 복잡한 퍼즐

### Reverse Gravity

목적:
- 일정 주기마다 중력 방향이 바뀌는 압박감 제공
- 플레이어가 곧 바뀔 중력을 예측하며 이동하게 만들기

필수:
- 일정 시간마다 중력 방향 변경
- 간단한 VFX로 다음 중력 방향 예고
- 플레이어와 물리 오브젝트가 함께 반응
- 적 또는 잔해를 통해 주기적 중력 변화가 눈에 보이게 연출

제외:
- 대형 전투 이벤트
- 복잡한 타이밍 퍼즐

### Zero Gravity

목적:
- 무중력 상태에서 그래플링 훅으로 이동하는 핵심 구간

필수:
- 플레이어 중력 제거 또는 크게 감소
- 우클릭으로 그래플링 훅 발사
- 카메라 중심 Raycast로 지형 감지
- 적중 지점으로 플레이어를 끌어당김
- LineRenderer로 간단한 로프 표시 가능

제외:
- 실제 로프 시뮬레이션
- 줄 감기
- 복잡한 스윙 물리
- 무중력 전투 완성도

### Source

목적:
- 게임 종료 지점
- 이상 현상의 근원을 확인하고 스캔

필수:
- 스캔 대상 오브젝트
- I 키 상호작용
- 스캔 완료 시 엔딩 UI 또는 엔딩 상태 전환

제외:
- 보스전
- 컷신
- 긴 대사

## 6. 입력 규칙

입력은 Unity의 기존 입력 API를 사용합니다.

```text
WASD: 이동
Space: 점프
Left Shift: 전진 달리기
Left Ctrl: 웅크리기
R: 재장전
I: 상호작용
마우스 이동: 카메라 시야 회전
마우스 좌클릭: 총 발사
마우스 우클릭: 그래플링 훅 발사
```

현재 입력 래퍼:

```text
Assets/_Scripts/Input/MvpPlayerInput.cs
```

구현 규칙:
- 플레이어 관련 스크립트는 `MvpPlayerInput`에서 입력값을 읽습니다.
- 여러 스크립트에서 직접 `Input.GetKey`, `Input.GetAxis`, 마우스 입력을 호출하지 않습니다.
- 입력 차단은 `MvpPlayerInput`의 플래그를 통해 1차 처리합니다.

입력 차단 예시:
- 일반 플레이: 이동, 시야, 전투, 그래플, 상호작용 모두 허용
- 대화 중: 이동, 전투, 그래플 차단 / 상호작용은 허용
- 컷신 또는 엔딩: 모든 입력 차단

## 7. 신규 담당자 작업 범위

신규 담당자는 우선 아래 시스템을 담당합니다.

- 플레이어 이동
- 플레이어 카메라
- 점프
- Left Shift 전진 달리기
- Left Ctrl 웅크리기
- 중력 방향 변경
- 무중력 이동
- 그래플링 훅 이동

권장 클래스 분리:

```text
MvpPlayerInput
- 입력 읽기
- 입력 차단 처리

PlayerController
- 이동
- 점프
- 전진 달리기
- 웅크리기
- 현재 중력 기준으로 플레이어 정렬

PlayerCameraController
- 마우스 시야 회전
- 플레이어 따라가기

GravityManager
- 현재 중력 방향과 세기 저장
- 중력 변경 이벤트 제공

GravityZone
- 구역 진입 시 GravityManager에 중력 변경 요청

GravityBody
- Rigidbody 오브젝트에 현재 중력 적용

GrapplingHook
- 우클릭 Raycast
- 그래플 적중 지점 저장
- LineRenderer 로프 표시
- 플레이어를 적중 지점 방향으로 끌어당김
```

중요:
- 입력 클래스는 Shift와 Ctrl의 눌림 상태를 각각 전달합니다.
- `PlayerController`는 Grounded·Crouch 상태에 따라 전진 달리기와 웅크리기 가능 여부를 판단합니다.

## 8. 전투 MVP

전투는 중력 시스템을 보여주기 위한 보조 요소입니다.

필수:
- 무기 1개
- 좌클릭 사격
- 단순 hit detection
- 적 체력
- 플레이어 체력
- 적 1종
- 적은 플레이어에게 접근하고 공격

시간이 남으면 추가:
- 적 1종 추가
- 재장전 연출
- 피격 이펙트
- 사망 연출

제외:
- 인벤토리
- 무기 교체
- 방어구
- 스킬 트리
- 복잡한 AI

## 9. 그래플링 훅 MVP

목표:
- 무중력 구간에서 벽과 벽 사이를 빠르게 이동하는 액션 제공

최소 동작:
- 우클릭 시 카메라 중심에서 Raycast
- 유효한 지형에 맞으면 hit point 저장
- 플레이어 또는 총구에서 hit point까지 선 표시
- 플레이어를 hit point 방향으로 끌어당김
- 도착, 시간 초과, 입력 해제 등의 조건으로 종료

제외:
- 실제 로프 물리
- 로프 감기
- 복잡한 진자 운동

## 10. 중력 연출

대표 연출:
- 중력이 바뀐다.
- 플레이어, 적, 잔해, 물리 오브젝트가 동시에 새 방향으로 떨어진다.
- 방 전체의 바닥 개념이 바뀐 것처럼 보인다.

최소 오브젝트:
- 박스
- 돌
- 금속 잔해
- 적 또는 시체 대체 오브젝트

MVP에서는 단순 Rigidbody 오브젝트면 충분합니다.

## 11. 4일 개발 일정

**일정은 확정된 것은 아니므로, 참고는 하되 유연하게 조정 가능**

### Day 1 - 기본 플레이

목표:
- 플레이어가 움직이고, 카메라가 따라가고, 점프하고, 사격하고, 적을 처치할 수 있다.

완료 기준:
- 이동 가능
- 카메라 회전 가능
- 점프 가능
- 사격 가능
- 적 1마리 처치 가능

### Day 2 - 중력 시스템

목표:
- 구역에 따라 중력 방향이 바뀐다.

완료 기준:
- 플레이어가 변경된 중력에 반응
- Rigidbody 오브젝트가 변경된 중력 방향으로 낙하
- 정상, 방향 변화, 주기적 중력 변화 구역이 플레이 가능

### Day 3 - 무중력과 엔딩

목표:
- 무중력, 그래플링, 최하부 스캔, 엔딩을 연결한다.

완료 기준:
- 플레이어가 그래플로 무중력 구간을 통과
- Source 구역 도달 가능
- I 키로 스캔 가능
- 스캔 완료 시 엔딩 처리

### Day 4 - 빌드와 증명

목표:
- 보여줄 수 있는 프로토타입으로 정리한다.

완료 기준:
- 처음부터 엔딩까지 3회 연속 플레이 성공
- 막히는 콜라이더 수정
- 최소 안내 UI 추가
- 실행 빌드 생성
- 짧은 플레이 영상 녹화

## 13. MVP 완료 기준

MVP는 아래 조건을 만족하면 완료로 봅니다.

- 에디터 조작 없이 Entry에서 Source까지 진행 가능
- 적 1마리 이상을 사격으로 처치 가능
- 최소 3가지 중력 상태가 플레이 중 확인 가능
- 무중력 구간은 그래플링 훅으로 통과
- Source 스캔 후 게임 종료
- 실행 빌드 또는 짧은 플레이 영상으로 결과 증명 가능
